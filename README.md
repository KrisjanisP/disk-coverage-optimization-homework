## Problem

**Input.** *N* points with integer coordinates in the plane, \([(x_1,y_1),\ldots,(x_n,y_n)]\), a natural number *K* (number of disks), and a radius \(R>0\).

**Disks.** Each disk has radius \(R\). Centers may be real (not necessarily integer).

**Goal.** Place the *K* disks so that as many input points as possible are covered.
A point is covered if its Euclidean distance to at least one disk center is at most \(R\).

This is the maximum-coverage problem with *K* equal disks of radius \(R\).

### Discretization

The continuous placement problem is equivalent to a discrete one: there is an optimal solution in which every disk is chosen from a finite candidate set.

A covered set of points has a smallest enclosing disk determined by at most three of those points on the boundary.
Keep a candidate whenever that disk has radius \(\le R\).
There are \(O(N^3)\) triples.

A tighter equivalent set has size \(O(N^2)\): centers of radius-\(R\) disks whose boundary passes through two input points (at most two such centers per pair at distance \(\le 2R\)), plus one-point placements (center at the point).
Implementation uses that \(O(N^2)\) set, then snaps each centre onto the integer lattice so the neighbourhood stays searchable when \(N\) is thousands.
A house is still covered by Euclidean distance \(\le R\), not by grid membership of the centre.

Once candidates are fixed, a solution is a choice of *K* candidate centers.

## Status

Problem chosen; not yet confirmed by the lecturer.
The first email to the lecturer stated radius one; the formulation here uses a general radius \(R\) on a larger integer map.

Algorithm: tabu search (random start, sample 2500 unused candidates per step, tenure 12, restart after 20 idle steps).
Baseline: naive first-improvement hill-climbing until a local minimum, restarted from random $K$-subsets, same wall-clock (60 s).
LAHC lost to that baseline on an earlier map, so it is not the submitted method.

Solver: `python -m solver --instance data/instances/houses_n10000_k12_r10.txt --seconds 60`.

On a 60 s budget: naive HC covered **9104**/10000 (3 local minima); tabu search covered **9089** (75 sampled steps).
